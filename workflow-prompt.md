Goal: A funder(user) has a mission and wants to determine whether/how a proposal aligns with their mission and knows whether or not they should fund the proposal.

User uploads organizational/program mission statement -> User uploads proposal -> (1) system extracts "submitter profile" (as MIRA objects) which is details about the person submitting the proposal. The user will want to know about the collaborations and domains they've worked in, that sort of thing. (2) system extracts the MIRA objects of the proposal documents itself. (3). System extracts MIRA objects from prior art/citations in the proposal documents. -> an algorithm (to be designed later) processes these extractions etc. -> the UI has 4 sections the user wants to know: (1) How does this person stand in relation to collaborations etc. (2) What does the proposal propose (as MIRA objects). (3) How does this proposal relate to the larger and/or local ecosystem of research? (4) Mission alignment metric (to be designed later)
